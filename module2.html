01 · LEARN

What is a CMS?

A Content Management System (CMS) is software that helps users create, edit, organize and manage website content without needing to write all the website code manually.

Simple Example

Imagine you own a bakery website. You want to add a new cake, change its price, upload a product image and publish a blog post.

With a CMS, you can perform these tasks through an administration dashboard instead of manually editing every HTML page.

What can you manage using a CMS?

Pages

Create About, Home, Contact and other website pages.

Images

Upload and manage website images and media files.

Blog Posts

Publish articles, news and updates.

Products

Add products, descriptions and prices.

Users

Manage website users and permissions.

Plugins

Add extra website functionality using supported extensions.

02 · PLATFORMS

What is WordPress?

WordPress is a popular open-source Content Management System used to create blogs, business websites, portfolios, educational websites and online stores.

WordPress Example

A computer training institute wants a website containing Home, About, Courses, Gallery, Blog and Contact pages.

Using WordPress, the institute can create these pages, select a theme, add images and manage content through the dashboard.

Important WordPress Features

Themes

Control the appearance and layout of a website.

Plugins

Add features such as contact forms, SEO and security.

Dashboard

Manage pages, posts, media and settings.

Media Library

Store and manage images, videos and documents.

Users

Assign roles and permissions to website users.

SEO Support

Use SEO plugins and content practices to improve search visibility.

💡 Remember: WordPress is a CMS. WordPress.org provides the open-source software that can be installed on compatible hosting. WordPress.com is a hosted service with different plans and features.
03 · E-COMMERCE PLATFORM

What is Shopify?

Shopify is a hosted e-commerce platform that helps businesses create and manage online stores.

Shopify Example

A clothing shop wants to sell T-shirts, jeans and shoes online. The owner needs product pages, shopping cart, checkout and order management.

Shopify provides tools to build and manage this online store without the business owner having to manage the entire server infrastructure.

Important Shopify Features

Product Management

Add products, images, prices and descriptions.

Shopping Cart

Allow customers to collect products before checkout.

Checkout

Provide a checkout process for customer orders.

Payments

Configure supported payment providers.

Order Management

View and manage customer orders.

Store Themes

Customize the appearance of an online store.

04 · E-COMMERCE PLATFORM

What is WooCommerce?

WooCommerce is an open-source e-commerce plugin for WordPress. It adds online store functionality to a WordPress website.

WooCommerce Example

A bakery already has a WordPress website. Now the owner wants to sell birthday cakes, chocolates and gift boxes online.

By installing WooCommerce, the website can support product listings, cart, checkout and order management.

WooCommerce Features

Products

Add simple and variable products.

Categories

Organize products into categories.

Cart

Allow customers to add and review products.

Checkout

Collect customer and delivery details.

Payments

Configure compatible payment gateways.

Reports

Review store orders and sales information.

💡 Remember: WooCommerce is not a separate CMS. It is an e-commerce plugin that works with WordPress.
05 · CUSTOM DEVELOPMENT

What is Custom Website Development?

Custom website development means building a website according to specific business requirements using programming languages, frameworks and development tools.

Example

A school wants a student management portal with student login, attendance, marks, fees, staff accounts and examination reports.

If existing platforms do not meet all these requirements, developers can build a custom application.

Technologies Used

HTML

Creates the structure of web pages.

CSS

Controls design, layout and appearance.

JavaScript

Adds interactivity and dynamic behaviour.

Python / PHP

Can be used to develop server-side functionality.

MySQL

Stores and manages application data.

Django / Laravel

Frameworks for building web applications.

UNDERSTAND

CMS vs Custom Development

Feature CMS Custom Development
Development Uses an existing platform Built according to requirements
Coding Knowledge Less coding may be required Programming knowledge is usually required
Customization Depends on themes and extensions Greater control over functionality and design
Development Time Often faster to launch Can take longer
Maintenance Platform, plugin and hosting updates Developer-managed maintenance
Examples WordPress, Shopify Custom Django or PHP application
💡 Important: CMS is not always better than custom development, and custom development is not always better than CMS. The correct choice depends on the business requirements, budget, skills, timeline and maintenance needs.
PLATFORM SELECTION

Which Platform Should You Choose?

BUSINESS WEBSITE

WordPress

Suitable for business websites, blogs, portfolios and content-driven websites.

ONLINE STORE

Shopify

Suitable for businesses that want a hosted platform to manage online selling.

WORDPRESS STORE

WooCommerce

Suitable for adding e-commerce features to an existing WordPress website.

SPECIAL APPLICATION

Custom Development

Suitable for specialized portals, dashboards and complex business applications.

06 · DO

Student Practical

In this module, students will explore website platforms and understand how to create and manage websites using CMS tools.

PRACTICAL 01

Explore the WordPress Dashboard

Learn how WordPress helps users manage website content.

Your task:

  1. Open a WordPress installation provided by your trainer or create a training website.
  2. Login to the WordPress administration dashboard.
  3. Explore Dashboard, Posts, Pages, Media and Appearance.
  4. Create a new page called About Us.
  5. Add a heading, paragraph and image.
  6. Publish the page and view it on the website.

Deliverable

Submit the WordPress website URL and screenshots of the dashboard and published About Us page.

PRACTICAL 02

Install and Explore a WordPress Theme

Understand how themes control the appearance of a WordPress website.

Your task:

  1. Open the WordPress dashboard.
  2. Go to Appearance → Themes.
  3. Explore the available themes.
  4. Preview a suitable theme for a business website.
  5. Activate the selected theme.
  6. Check the website layout on desktop and mobile.

Deliverable

Submit the selected theme name and before/after screenshots of your website.

PRACTICAL 03

Explore Plugins and Website Features

Learn how plugins add extra functionality to a WordPress website.

Your task:

  1. Open Plugins in the WordPress dashboard.
  2. Explore plugins for contact forms, SEO and security.
  3. Identify the purpose of each selected plugin.
  4. Install a suitable plugin in your training environment.
  5. Activate it and explore its settings.
  6. Demonstrate the added feature on your website.

Deliverable

Submit three plugin names, their purposes and screenshots of the installed plugin.

PRACTICAL 04

Plan an Online Store Using WooCommerce

Understand how a WordPress website can become an online store.

Your task:

  1. Open a WordPress training website.
  2. Explore WooCommerce and its requirements.
  3. Install WooCommerce in the training environment if available.
  4. Explore Products, Categories, Orders and Store Settings.
  5. Create a sample product with name, price, description and image.
  6. Preview the product page and shopping cart.

Deliverable

Submit a sample product page screenshot and a short explanation of how WooCommerce works.

⚠️ Important: Use a local or trainer-provided training website. Do not connect real payment gateways or publish real customer information during practice without authorization.
