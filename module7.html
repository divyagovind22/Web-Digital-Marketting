UNDERSTAND THE DATA

What Do These Numbers Mean?

Learn the important metrics available in Google Search Console.

Clicks

How many times users clicked the website from Google Search.

Impressions

How many times a website result was shown in Google Search.

CTR

The percentage of impressions that resulted in clicks.

Average Position

An average position metric for the site's results in the selected Search Console data.

Queries

Search terms for which the website received impressions or clicks.

Remember: A new or low-traffic website may not have enough Search Console data yet. Students can still practise property verification and URL Inspection, and record that performance data is not yet available.

FINAL AUDIT

From Data to Action

The goal is not simply to generate an SEO report. Students should use the information to decide what needs to be improved first.

Problem

What SEO issue did you find?

Evidence

Which tool or observation showed the problem?

Priority

Is this a high, medium or low priority issue?

Action

What specific change should be made?

Expected Result

What improvement do you expect from the action?

Audit Formula: Problem → Evidence → Priority → Action → Expected Result
